# 영상 화질 보존

원본을 받아 편집하고 최종 MP4를 내보내기까지 눈에 보이는 디테일을 지킨다. 파일 용량이 줄었다는 사실만으로 화질 저하를 단정하지 않는다. 이미 손실된 원본의 디테일은 비트레이트를 높여도 되살릴 수 없다.

## 편집 전

1. 카메라 영상과 화면 녹화의 **원본 파일을 그대로 보존**한다. 프록시, 메신저에 올린 파일, 미리보기 파일을 원본 대신 쓰지 않는다.
2. `ffprobe`로 원본의 코덱·해상도·프레임률·픽셀 형식·비트레이트를 기록한다.

   ```bash
   ffprobe -v error -select_streams v:0 -show_entries stream=codec_name,width,height,avg_frame_rate,pix_fmt,bit_rate -of json "SOURCE.mp4"
   ```

3. 목표 출력의 해상도·화면 비율·프레임률을 정한다. 숫자만 높이려고 업스케일하지 않는다. 별도 이유가 없다면 30fps 원본을 60fps로 바꾸지 않는다.

## 컷과 렌더

- 침묵·말실수 제거는 원본 기준의 타임스탬프 또는 EDL(컷 결정표)로 관리한다. 압축 MP4를 만들고 그 파일을 다시 압축하는 연쇄 작업을 피한다. 자막의 작은 글씨와 화면 녹화는 반복 인코딩의 영향을 특히 살핀다.
- 중간 파일이 꼭 필요하면 무손실 또는 시각적으로 손실이 거의 없는 형식을 고르고 저장 공간 증가를 알린다. 단순 컷에 스트림 복사를 쓸 때는 키프레임 경계와 음성 싱크를 확인한다.
- HyperFrames 컴포지션의 크기와 화면 비율을 목표 출력에 맞춘다. 원본을 지나치게 확대하거나 잘라 글씨·얼굴이 흐려지지 않았는지 미리보기와 인코딩 결과 모두에서 확인한다.
- `draft`는 검토용으로만 쓴다. 최종본은 설치된 HyperFrames 버전에서 지원하는 옵션을 확인하고 `high`로 렌더한다.

   ```bash
   npx hyperframes render --quality high --output renders/final.mp4
   ```

- 화면 녹화·UI·색상 그래픽에는 지원 버전에서 `--video-frame-format png`를 추가해 JPEG 프레임 추출로 생길 수 있는 열화를 피한다. 최종 인코딩이 실제로 흐릴 때만 대표 구간에서 `--crf 18`과 더 낮은 값을 비교한다. CRF를 낮추면 보통 파일이 커진다. `--crf`와 `--video-bitrate`는 동시에 쓰지 않는다. 선택 옵션은 `npx hyperframes render --help`로 확인한다.
- 파일 용량만 줄이려고 최종본을 FFmpeg로 한 번 더 압축하지 않는다. 오디오만 수정할 때 컨테이너와 코덱이 허용하면 `-c:v copy`로 영상 스트림을 복사하고 음성 싱크를 다시 확인한다.

## 실제 출력 검수

1. 최종 MP4에도 같은 `ffprobe` 명령을 실행한다. 해상도·프레임률·픽셀 형식이 바뀌었다면 의도한 변경인지 설명한다.
2. **원본과 최종본의 같은 장면**을 화면 100% 크기로 비교한다. 컷 편집으로 시각이 달라졌다면 EDL로 대응 지점을 찾는다. 얼굴 근접 장면, 작은 글씨, 움직임, 어둡거나 명암이 큰 장면을 가능한 범위에서 확인한다. 선명도·블록 노이즈·색·밴딩·프레임 누락/중복·음성 싱크를 본다. 자막이나 그래픽이 덮인 부분은 원본 화질 비교에서 제외한다.
3. 브라우저 미리보기만 보지 말고 **인코딩된 최종 MP4**에서 대표 프레임을 추출한다.

   ```bash
   ffmpeg -ss 00:00:30 -i renders/final.mp4 -frames:v 1 -update 1 final-check.png
   ```

4. 결함이 보이면 원본 → 프레임 추출 → 중간 컷 파일 → 컴포지션 확대/잘림 → 최종 인코딩 → 업로드 플랫폼 재인코딩 중 **처음 결함이 나타난 단계**를 찾고 그 단계를 수정한다. 로컬 완성본과 플랫폼에서 재생되는 영상은 따로 판단한다.
5. 최종 렌더 설정, 원본·출력 메타데이터, 눈으로 확인한 시점, 남은 결함을 기록한다. 성공한 렌더 명령이나 파일 크기·비트레이트만으로 화질을 보증하지 않는다. 20분 원본을 약 10분으로 줄이는 사례라면 완성본의 앞·중간·끝에서 각각 대응 장면을 확인한다.
